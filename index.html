Install EXOpace

This browser did not offer a one-tap install. Add it from the browser menu:

  1. iPhone / iPad Safari: Share → Add to Home Screen.
  2. Chrome / Edge: menu ⋮ → Install app (or Add to Home screen).
  3. Firefox: desktop Firefox cannot install web apps; use Chrome or Edge.
