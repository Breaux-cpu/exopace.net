    LOADING

    Click a page. Click it again to drop it. Shift-drag fills an area. A letter page steps 1 km. A USGS quadrangle steps to the next cell. Arrow keys nudge the selected page.

    MEASURE

    Each click adds a point, up to 24. The latest leg is a WGS84 geodesic. Azimuth is clockwise from north at the start of that leg. Grid north uses that point’s UTM zone. Magnetic north is the World Magnetic Model when NOAA answers. Slope uses those elevations as the rise. ROUTE GPX is a track to import in ATAK or another GPS app. PDF, ATAK, and Garmin pages draw that route on each page it crosses. Every leg shows its own true, grid, and back azimuth. Magnetic azimuth stays with that leg after NOAA answers for its start. The link keeps the route to about one meter.

    LAYERS

    Power lines and pipelines are OpenStreetMap via OpenInfraMap. Flood zones are FEMA NFHL, United States only. 3DEP is USGS shaded relief, not a lidar point cloud. Ham and leaf type are OpenStreetMap tags for this view. Untagged woods stay in WOODS. A missing ham point is not a statement that no repeater exists.

    USGS SCAN

    FIND USGS SCAN asks the USGS catalogue for the scanned paper map of the selected quadrangle. Each year opens their GeoPDF, collar included. SHOW crops that year's scan to the quadrangle. The link keeps that year, and opening the link places it again. The picture is the sharpest overview under about 1.2 MB, not the full sheet. Print draws it in the neatline of the letter pages. The collar names the next cell on each side by that cell's corner. A WGS84 sheet uses transverse mercator. A CONUS NAD27 polyconic sheet is shifted with the published three-parameter datum. Any other projection stays off the map.

    Pick a USGS quadrangle, then find its scan.

    PRINT

    Letter sheets print on US Letter at actual size. A USGS quadrangle prints as true-scale letter tiles of that latitude and longitude cell. The 1 km bar is 40 mm at 1:25,000. Measure the 100 mm bar. A measured route is drawn in the neatline of each page it crosses, and the collar says so. On a quadrangle, the collar also names the next cell north, east, south, and west by that cell's corner. A cell past the sheet grid is omitted.

    ATAK

    SEND TO ATAK builds a KMZ of the pages. When a route is measured, that file also contains the route as its own line, clamped to the ground, plus a numbered point for each click. ATAK MBTILES packs imagery for the selected sheets into one raster file. Copy it into ATAK or use Import. It is not a world download. Esri, Maxar, Earthstar Geographics. ATAK-CIV is not installed on this phone, so this page cannot finish the import. GARMIN KMZ is a Custom Map for Garmin/CustomMaps. Each image is at most 1024 px. No Garmin drive is connected here, so it has not been loaded on a Garmin. The XML links are online basemaps. Finish ATAK’s callsign screen yourself.
